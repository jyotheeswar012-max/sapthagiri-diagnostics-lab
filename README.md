## 📊 Key Features

| Feature | Description |
|---|---|
| 👤 **Patient Records** | Add, view & manage patient profiles |
| 🧪 **Test Management** | Blood tests, scans & report generation |
| 📅 **Appointments** | Online slot booking & scheduling |
| 📊 **Reports Dashboard** | Visual summary of lab operations |
| 📱 **Responsive UI** | Works on desktop, tablet & mobile |
